1 O que é o R?

O R é uma linguagem de programação gratuita e open-source especializada em análise estatística e visualização de dados. É amplamente utilizado em química analítica, quimiometria, análise ambiental e farmacologia. Suas principais vantagens são:

  • Totalmente gratuito e multiplataforma (Windows, macOS, Linux)
  • Mais de 20.000 pacotes na CRAN (repositório oficial)
  • Ideal para quimiometria: PCA, PLS, HCA, calibração multivariada
  • Integração com Excel, CSV, banco de dados e instrumentos analíticos
  • Produção de gráficos científicos de alta qualidade (publicação)
O RStudio é a IDE (ambiente de desenvolvimento) recomendada para trabalhar com R. Instale o R primeiro, depois o RStudio.

2 Instalação do R

Windows

  1. Acesse cran.r-project.org e clique em "Download R for Windows"
  2. Clique em "base" → "Download R x.x.x for Windows"
  3. Execute o instalador baixado (.exe) como administrador
  4. Mantenha todas as opções padrão e finalize a instalação
Para verificar a instalação, abra o Prompt de Comando e digite R --version

macOS

  1. Acesse cran.r-project.org → "Download R for macOS"
  2. Baixe o arquivo .pkg adequado ao seu chip (Intel ou Apple Silicon/M1/M2/M3)
  3. Execute o instalador e siga as instruções
Usuários de Mac com chip Apple Silicon (M1/M2/M3): baixe a versão "Apple silicon (M1 and above)" para melhor desempenho.

Linux (Ubuntu/Debian)

Terminal 
sudo apt update
sudo apt install r-base r-base-dev

3 Instalação do RStudio

  1. Acesse posit.co/download/rstudio-desktop
  2. Clique em "Download RStudio Desktop" (versão gratuita)
  3. Baixe o instalador para seu sistema operacional
  4. Execute e instale (o RStudio detecta automaticamente o R instalado)
O RStudio possui 4 painéis: Editor de Script, Console, Ambiente/Histórico e Arquivos/Gráficos/Pacotes.

Estrutura do RStudio

  • Editor (superior esquerdo): escreva e salve seus scripts .R
  • Console (inferior esquerdo): executa comandos em tempo real
  • Environment (superior direito): variáveis e objetos criados
  • Plots/Files/Packages (inferior direito): gráficos, arquivos, pacotes

7 Estatística Descritiva

R 
valores <- c(12.3, 11.8, 12.5, 12.1, 12.4, 11.9, 12.2)

mean(valores)      # média
median(valores)    # mediana
sd(valores)        # desvio padrão
var(valores)       # variância
range(valores)     # mínimo e máximo
quantile(valores)  # quartis

# Coeficiente de variação (CV%)
cv <- (sd(valores) / mean(valores)) * 100
cat("CV% =", round(cv, 2), "%\n")

# Erro padrão da média (SEM)
sem <- sd(valores) / sqrt(length(valores))
cat("SEM =", round(sem, 4), "\n")

# Intervalo de confiança 95%
t.test(valores)$conf.int

Teste de normalidade

R # Shapiro-Wilk (recomendado para n < 50) shapiro.test(valores) # p > 0.05 → dados normalmente distribuídos # Q-Q plot visual qqnorm(valores) qqline(valores, col = "red")

Teste t e ANOVA

R 
# Teste t para comparar 2 grupos
grupo_a <- c(12.3, 11.8, 12.5, 12.1)
grupo_b <- c(13.1, 13.4, 12.9, 13.2)
t.test(grupo_a, grupo_b)  # bicaudal

# ANOVA para 3 ou mais grupos
library(agricolae)
grupos <- c(rep("A",4), rep("B",4), rep("C",4))
respostas <- c(12.3,11.8,12.5,12.1, 13.1,13.4,12.9,13.2, 11.2,11.0,11.5,11.3)
modelo <- aov(respostas ~ grupos)
summary(modelo)
# Pós-teste Tukey
TukeyHSD(modelo)

8 Regressão Linear — Curva Analítica

R # Dados de uma curva analítica concentracao <- c(0.1, 0.5, 1.0, 2.0, 5.0, 10.0) absorbancia <- c(0.023, 0.112, 0.224, 0.447, 1.115, 2.231) # Regressão linear modelo <- lm(absorbancia ~ concentracao) summary(modelo) # Extrair parâmetros coef(modelo) # intercepto e coeficiente angular summary(modelo)$r.squared # R² # Coeficiente de correlação de Pearson cor(concentracao, absorbancia) # Calcular a concentração de uma amostra desconhecida (abs = 0.680) abs_amostra <- 0.680 a <- coef(modelo)[2] # coef. angular b <- coef(modelo)[1] # intercepto conc_amostra <- (abs_amostra - b) / a cat("Concentração da amostra:", round(conc_amostra, 4), "\n") # Calcular Limite de Detecção (LD) e Limite de Quantificação (LQ) sigma <- summary(modelo)$sigma # desvio padrão dos resíduos LD <- (3.3 * sigma) / a LQ <- (10 * sigma) / a cat("LD =", round(LD, 5), "| LQ =", round(LQ, 5), "\n")
Um R² ≥ 0.999 indica excelente linearidade para curvas analíticas em Química Analítica.

9 Gráficos com ggplot2

Curva analítica com linha de regressão

R 
library(ggplot2)

concentracao <- c(0.1, 0.5, 1.0, 2.0, 5.0, 10.0)
absorbancia  <- c(0.023, 0.112, 0.224, 0.447, 1.115, 2.231)
dados <- data.frame(concentracao, absorbancia)

ggplot(dados, aes(x = concentracao, y = absorbancia)) +
  geom_point(size = 3, color = "#1a3560") +
  geom_smooth(method = "lm", se = TRUE,
              color = "#2a6496", fill = "#c7d7f0") +
  labs(
    title    = "Curva Analítica — Absorção Atômica",
    subtitle = paste0("R² = ", round(summary(lm(absorbancia~concentracao))$r.squared, 5)),
    x        = "Concentração (mg/L)",
    y        = "Absorbância"
  ) +
  theme_classic(base_size = 13) +
  theme(plot.title = element_text(face = "bold"))

# Salvar em alta resolução (300 dpi — publicação)
ggsave("curva_analitica.png", width = 8, height = 5, dpi = 300)

10 Quimiometria — Análise de Componentes Principais (PCA)

R 
library(FactoMineR)
library(factoextra)

# Exemplo com dados de metais em amostras ambientais
set.seed(42)
metais <- data.frame(
  Pb = c(12,14,11,45,48,43,8,7,9),
  Cd = c(0.5,0.6,0.4,1.8,2.0,1.7,0.2,0.3,0.2),
  Cu = c(25,27,24,40,42,38,18,19,17),
  Zn = c(80,85,78,150,160,145,55,58,52),
  Fe = c(500,520,490,800,850,790,400,420,390)
)
rownames(metais) <- paste0("Amostra_", 1:9)

# Calcular PCA (escala padronizada = TRUE, recomendado)
pca <- PCA(metais, scale.unit = TRUE, graph = FALSE)

# Variância explicada
fviz_eig(pca, addlabels = TRUE, ylim = c(0, 70),
         barfill = "#1a3560", barcolor = "#1a3560") +
  labs(title = "Variância Explicada por Componente")

# Biplot: amostras + variáveis
fviz_pca_biplot(pca,
  col.ind = "#1a3560",   # cor dos pontos (amostras)
  col.var = "#dc2626",   # cor das setas (variáveis)
  repel   = TRUE         # evita sobreposição de textos
) + theme_classic()

# Contribuição das variáveis
fviz_contrib(pca, choice = "var", axes = 1, fill = "#2a6496")
Variáveis com contribuição acima da linha vermelha tracejada no gráfico de contribuições são as mais importantes para a componente principal.

Análise de Cluster Hierárquico (HCA)

R 
library(factoextra)

# Calcular distâncias euclidianas (dados padronizados)
metais_scaled <- scale(metais)
distancias    <- dist(metais_scaled, method = "euclidean")

# Agrupamento hierárquico Ward.D2
hca <- hclust(distancias, method = "ward.D2")

# Dendrograma
fviz_dend(hca, k = 3,              # 3 clusters
          cex = 0.9,
          color_labels_by_k = TRUE,
          rect = TRUE,
          main = "Dendrograma — HCA Ward.D2"
)
