1 Introdução ao Processamento de RMN

A Ressonância Magnética Nuclear (RMN) é uma das ferramentas mais poderosas para elucidação estrutural de compostos orgânicos. Os espectros brutos gerados pelo espectrômetro precisam ser processados por softwares específicos antes da interpretação.

As etapas fundamentais do processamento são:

  1. FT (Transformada de Fourier): converte o FID (Free Induction Decay) em espectro de frequências
  2. Correção de fase: ajusta a simetria dos picos (fase zero e primeira ordem)
  3. Correção de linha de base: nivelar a linha de referência do espectro
  4. Calibração do deslocamento químico (δ): referência interna (TMS = 0 ppm) ou solvente
  5. Integração dos sinais: área dos picos proporcional ao número de prótons
  6. Multiplicidade e constante de acoplamento (J): análise dos padrões de acoplamento spin-spin

Fluxo básico no MestReNova

1

Abrir o espectro

Arraste o arquivo FID (pasta Bruker ou arquivo .fid, .jdf, .dx) para a janela do Mnova. O software realiza a FT automaticamente.

2

Correção de fase

Clique em Processing → Phase Correction ou use o atalho F. Ajuste as alças "0" (fase zero) e "1" (primeira ordem) até todos os picos ficarem para cima com base simétrica.

3

Correção de linha de base

Vá em Processing → Baseline Correction. Para espectros de ¹H, o método "Bernstein Polynomial" geralmente é suficiente.

4

Calibração

Clique com o botão direito no pico de referência (TMS em 0 ppm, ou pico do solvente: CDCl₃ = 7.26 ppm para ¹H; 77.0 ppm para ¹³C) e selecione Assign Reference.

5

Integração

Use a ferramenta Integration (ícone ∫ na barra). Arraste sobre cada sinal. Clique com o botão direito em uma integral e defina o número de prótons de referência para calibrar as demais.

6

Multiplicidade e J

Ative Analysis → Multiplet Analysis. Clique sobre cada grupo de sinais. O Mnova identificará automaticamente o padrão (s, d, t, q, dd, etc.) e a constante J em Hz.

7

Exportar relatório

Vá em File → Save as PDF ou File → Report para gerar relatório completo com espectros, integrais e tabela de multiplicidades.

3 TopSpin (Bruker)

TopSpin — Bruker BioSpin
Gratuito para academia Windows macOS Linux

Software oficial da Bruker, gratuito para uso acadêmico. É o padrão de controle dos espectrômetros Bruker e o mais utilizado no LABAREMN/UEFS. Possui interface de linha de comando e GUI.

✓ Vantagens
  • Gratuito para academia
  • Padrão Bruker — controla o espectrômetro
  • Processamento robusto e preciso
  • Suporte completo a todos experimentos Bruker
  • Scriptável (Python e Jython)
✗ Desvantagens
  • Interface menos intuitiva
  • Curva de aprendizado íngreme
  • Apenas arquivos Bruker nativamente
Registro gratuito + Download

5 NMRium — Solução Online Gratuita

NMRium
Gratuito Navegador (sem instalação) Open Source

Solução moderna e gratuita para processamento de RMN diretamente no navegador, sem necessidade de instalação. Desenvolvido pela comunidade científica e mantido pela Cheminfo. Excelente para visualização rápida e análise básica.

✓ Vantagens
  • Sem instalação — funciona no navegador
  • 100% gratuito e open source
  • Multiplataforma (qualquer OS)
  • Suporte a Bruker, JCAMP-DX, NMReDATA
  • Interface moderna e intuitiva
  • Integração com bancos de dados
✗ Desvantagens
  • Recursos mais limitados que o Mnova
  • Requer conexão com internet
  • Em desenvolvimento contínuo
Acessar nmrium.org

Como usar o NMRium

  1. Acesse nmrium.org em qualquer navegador moderno
  2. Arraste a pasta do espectro Bruker (pasta contendo fid, acqus, procs) ou arquivo .jdx / .dx
  3. O NMRium realiza a FT automaticamente
  4. Use o painel lateral para ajustar processamento, integrar e atribuir sinais
  5. Exporte os dados em formato NMReDATA para publicação
O NMRium é a ferramenta recomendada para visualização rápida e para uso em computadores sem licença do Mnova.

8 Formatos de Arquivo de RMN

  • Bruker (pasta FID): pasta com arquivos fid, acqus, acqu2s (2D) e subpasta pdata/1/ com processados. Este é o formato do LABAREMN.
  • JCAMP-DX (.jdx, .dx): formato aberto e universal. Compatível com quase todos os softwares.
  • Varian/Agilent (.fid): pasta com arquivos fid, procpar, text
  • JEOL (.jdf): formato nativo dos espectrômetros JEOL
  • NMReDATA (.nmredata): formato moderno para deposição em publicações científicas com atribuição completa dos sinais
Os espectros do LABAREMN são fornecidos em formato Bruker. O MestReNova e o NMRium abrem este formato diretamente.

9 Fluxo de Trabalho Recomendado

Para análise rotineira (¹H e ¹³C)

1

Receber os dados do espectrômetro

Copie a pasta completa do experimento Bruker (ex: sample_001/) para seu computador.

2

Abrir no MestReNova ou NMRium

Arraste a pasta para o software. Inspecione o FID para verificar qualidade da aquisição (decaimento suave sem artefatos).

3

Processar (FT → fase → baseline)

Aplique janela de apodização adequada (LB = 0.3 Hz para ¹H; 1-3 Hz para ¹³C), FT, correção de fase e baseline.

4

Calibrar deslocamento químico

Ajuste o pico do solvente como referência: CDCl₃ = 7.26/77.0 ppm; DMSO-d₆ = 2.50/39.5 ppm; D₂O = 4.79 ppm (¹H).

5

Integrar e atribuir sinais

Integre cada sinal do ¹H e calibre com o grupo mais simples (ex: CH₃ = 3H). Realize a análise de multiplicidade para obter δ, multiplicidade, J e número de H.

6

Correlacionar experimentos 2D

Use COSY (H-H), HSQC (H-C direto, 1 ligação) e HMBC (H-C longa distância, 2-3 ligações) para atribuir todos os carbonos e confirmar a estrutura.

7

Exportar para publicação

Gere figuras em 300 dpi (PNG/TIFF) ou vetoriais (SVG/PDF). Para submissão: exporte os dados em NMReDATA ou inclua dados brutos como material suplementar.

10 Predição de Espectros de RMN

Para confirmar atribuições ou prever deslocamentos químicos de compostos sintéticos/naturais, utilize ferramentas de predição:

NMRshiftDB
GratuitoOnline

Banco de dados gratuito com mais de 50.000 espectros experimentais e predição por analogia estrutural. Acesse em nmrshiftdb2.nmr.uni-koeln.de

SDBS (AIST, Japão)
GratuitoOnline

Banco de dados espectroscópicos do AIST com RMN ¹H e ¹³C, IV, MS e Raman para milhares de compostos. Acesse em sdbs.db.aist.go.jp

MestReNova + NIST WebBook
Parcialmente gratuito

O MestReNova tem módulo de predição de ¹H e ¹³C integrado. Combine com o banco NIST WebBook (webbook.nist.gov) para comparar espectros experimentais e preditos.

Para compostos de produtos naturais, consulte também o Dictionary of Natural Products (DNP) via UEFS e o SciFinder para busca por deslocamento químico.
