Como Usar o Analisador IC₅₀

Siga os passos abaixo para inserir seus dados e obter a curva dose-resposta com o IC₅₀ calculado.

1

Escolha o modelo

No painel lateral, selecione Sigmoidal 4PL para curvas típicas dose-resposta (recomendado para IC₅₀), Linear para relações proporcionais, ou Log-Linear para eixo logarítmico. Defina também a escala do eixo X.

2

Insira os dados na tabela

Preencha a coluna Concentração com valores crescentes (ex: 0.001, 0.01, 0.1…). Nas colunas de réplica, insira os valores de inibição (%). Use + Linha para mais concentrações e + Réplica para mais replicatas. Mínimo: 4 pontos para 4PL, 2 para Linear.

3

Clique em Analisar

O sistema calcula automaticamente a média de cada concentração, ajusta a curva ao modelo selecionado e exibe o gráfico. Para o 4PL, uma linha tracejada vermelha indica o IC₅₀.

4

Interprete os resultados

O IC₅₀ é a concentração que produz 50% do efeito máximo. O R² indica qualidade do ajuste (ideal ≥ 0.99). Para 4PL, o coeficiente de Hill (H) indica a inclinação da curva.

5

Exporte o gráfico

Após gerar a análise, clique em Exportar gráfico em PNG no painel lateral. O arquivo é salvo em alta resolução.

🧬

O que é IC₅₀?

IC₅₀ (Inhibitory Concentration 50%) é a concentração de uma substância que inibe 50% de uma função biológica. É o principal parâmetro de potência em estudos farmacológicos e bioquímicos.

📐

Modelo 4PL

  • Base (b): resposta mínima
  • Topo (t): resposta máxima
  • IC₅₀: concentração no ponto médio
  • H (Hill): inclinação da curva sigmoidal
💡

Dicas

  • Use mínimo 6 concentrações para o 4PL
  • Inclua 3 réplicas por concentração
  • Cubra toda a faixa de resposta (0–100%)
  • Verifique se R² ≥ 0.99
